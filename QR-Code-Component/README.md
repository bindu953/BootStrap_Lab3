
# QR Code Component – Bootstrap and Tailwind CSS

## Project Overview

This project is part of the Frontend Mentor QR Code Component Challenge.

The goal was to refactor my original HTML and CSS project using Bootstrap and Tailwind CSS utility classes while keeping the design as close to the provided Figma design as possible.

## Technologies Used

- HTML5
- Bootstrap 5
- Tailwind CSS
- Google Fonts (Outfit)
- Visual Studio Code
- Git and GitHub

## Features

- Responsive QR code component
- Centered card using Bootstrap Flexbox utilities
- Rounded corners for the card and QR code image
- Custom colors and spacing using Tailwind CSS
- Outfit font with weights 400 and 700
- Mobile-friendly layout using responsive utility classes

## How to Run the Project

1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or a web browser.
4. View the QR Code Component.

Note: An internet connection is required to load Bootstrap, Tailwind CSS, and Google Fonts through their CDNs.

## What I Learned

Through this project, I learned how to:

- Use Bootstrap and Tailwind CSS utility classes.
- Apply Flexbox utilities to center elements.
- Replace regular CSS properties with framework classes.
- Customize colors, spacing, width, and border radius.
- Use responsive utility classes for different screen sizes.
- Understand the differences between Bootstrap and Tailwind CSS.
- Refactor existing HTML and CSS without changing the overall design.

## Challenges Faced

One challenge I faced was finding the correct Bootstrap and Tailwind classes to match my original CSS.

Some Bootstrap classes did not provide the exact spacing, colors, or sizes required by the Figma design. I used Tailwind's custom utility values to match the design more closely.

I also learned that Bootstrap and Tailwind sometimes use similar class names with different styling values, so I had to check and adjust the styles.

## Reflection

Refactoring this project helped me understand how CSS frameworks can simplify web development.

Bootstrap made it easier to create layouts and align elements using predefined utility classes, while Tailwind gave me more flexibility to customize the design.

I also learned that custom CSS can still be useful when a project requires specific styling.
